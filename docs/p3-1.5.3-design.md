## Common frame language

Menus, settings tabs, native tool/arcana frames, thinking headers, code/terminal headers, file previews, status/error rows, approval controls and the composer share fine cyan rules, navy strips and white/cyan/pink selection cues. Semantic error/warning/done colours and text remain. File preview overlays retain their native open/menu hit targets. Paragraphs, headings, lists, tables and code stay horizontal. The composer is a rule-and-tab dock; its opaque footer prevents scrolled text bleeding through the command hint. New menu movement is a single 140 ms slide; reduced motion disables it and row transitions. No flicker or infinite frame animation.
